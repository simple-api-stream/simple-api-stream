# @simple-api-stream/core

Core event classes, TypeScript interfaces, and shared utilities for the `simple-api-stream` package family.

## Installation

```bash
npm install @simple-api-stream/core
```

## Exports

### `@simple-api-stream/core`

- Event classes: `SAEvent`, `StartDocumentEvent`, `EndDocumentEvent`
- Event interfaces (types): `StartDocumentSAEventInterface`, `EndDocumentSAEventInterface`
- Parser interface (type): `SimpleApiParser<T>`

### `@simple-api-stream/core/utils`

- `assert`, `assertIsTrue`, `isTrue`
- `assertIsDefined`, `isDefined`
- `toErrorMessage`
- `functionToName`
